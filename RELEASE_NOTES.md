TaskFlow 1.2.7

- Desktop updates now download automatically at startup and during hourly checks. Choose Install and restart when ready.
- Both the full app and widget share one verified update download. Manual checks and release notes are available in Settings.
- All Tasks now uses richer cards with project-colored headers and sorting by project.
- Project workspace navigation and task details work in the Windows app, with project progress summaries and project-aware task creation.
- Dashboard backlog sits above the weekly chart, and Recent Activity appears below Upcoming Deadlines.
- Widget Focus now uses the same top-five selection and ranking as the main dashboard.

Users on 1.2.6 or earlier must install this release manually once to enable future in-app updates.
